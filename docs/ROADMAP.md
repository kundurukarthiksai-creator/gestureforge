# Product Roadmap

## Phase 1 — Converse and render

Prompt to validated procedural 3D scene. This is the only active phase.

## Phase 2 — Gesture control

Add on-device MediaPipe hand landmarks, an explicit camera permission flow, gesture smoothing, open-palm rotation, fist reset, and a manual-control fallback.

## Phase 3 — Persistence and sharing

Add accounts only if needed, store model specifications and conversation history, create shareable model pages, and support remixing.

Potential sponsor fit: MongoDB Atlas.

## Phase 4 — Provenance and telemetry

Measure gesture latency, render performance, and generation outcomes. Optionally anchor a design hash when a model is published.

Potential sponsor fit: Tiger Data and Solana.

## Phase 5 — Public hosting

Containerize the verified application, deploy behind HTTPS, add protected runtime secrets, connect a public domain, and complete observability.

Potential sponsor fit: AWS or Vultr for hosting and GoDaddy for the domain.

## Stretch ideas

- Export to GLB or STL.
- Two-hand scale and object selection.
- High-detail asynchronous mesh generation.
- Voice prompts.
- Collaborative review rooms.
- Accessible keyboard alternatives for every gesture.
