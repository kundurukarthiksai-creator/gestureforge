# Phase 1 Demo Plan

## 60-second story

“3D tools have a steep learning curve. GestureForge starts with the language people already know. I’ll ask for a neon lunar rover with six wheels and a sensor mast. The chatbot converts that request into a validated model specification, and the renderer assembles it immediately. I can orbit, zoom, and inspect the result from every side. The same contract lets us add hand control next—and if the AI provider or venue Wi-Fi fails, our deterministic engine preserves the entire demonstration.”

## Guaranteed prompts

- Neon lunar rover with six wheels and a sensor mast.
- Friendly service robot with glowing eyes.
- Satellite with solar panels and a dish.
- Futuristic vehicle with four wheels and a glass canopy.
- Abstract energy sculpture in the event colors.

## Failure rehearsal

- No AI key: fallback status is visible and a valid model renders.
- Provider timeout: request falls back automatically.
- Invalid provider JSON: validation rejects it and fallback renders.
- WebGL unavailable: the interface shows an actionable message.
- Slow laptop: reduce shadows and device pixel ratio before removing features.

## Evidence to capture later

- Hero screenshot showing chat and rendered scene together.
- Short recording from prompt submission to orbiting result.
- Architecture diagram.
- Clean GitHub repository and passing checks.
