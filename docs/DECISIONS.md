# Decision Log

## Decided

- Product name: GestureForge.
- Product line: “Say it. Shape it. Move it.”
- The overall product has five conceptual stages.
- The first implementation slice stops at interactive 3D rendering.
- Phase 1 uses a shared structured contract rather than direct provider-to-renderer coupling.
- Phase 1 must work without an AI key through a deterministic fallback.
- Procedural primitive composition is preferred over high-detail mesh generation for the first demo.
- Camera, database, blockchain, telemetry, and deployment work are deferred.
- No implementation is pushed until the plan and teammate division are agreed.

## Proposed

- Next.js, TypeScript, Gemini, Zod, React Three Fiber, and Three.js.
- Public GitHub repository under Karthik’s account.
- Karthik owns chat and generation; Shiva owns contract and rendering.
